# Texturas Minecraft (Opcional)

Para o easter egg do Konami Code funcionar com texturas, adicione:

- grass-dirt.png (textura de grama/terra do Minecraft)
- cobblestone.png (textura de pedra do Minecraft)

Tamanho recomendado: 64x64px ou 128x128px

Onde conseguir:
1. Extrair do Minecraft (se você possui o jogo)
2. Procurar por "Minecraft texture pack" online
3. Criar suas próprias texturas pixel art

NOTA: As texturas são OPCIONAIS. O modo Minecraft funciona sem elas,
apenas mudando as cores do site.
