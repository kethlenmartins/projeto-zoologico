# Adicione arquivos de áudio aqui

Arquivos necessários:
- background-music.mp3 (música de rock para tocar de fundo)
- golaco.mp3 (som de "GOLAÇO" ou narração de gol)

Formato recomendado: MP3
Taxa de bits: 128-192 kbps

Sugestões de músicas de rock:
- Linkin Park - In The End
- Foo Fighters - The Pretender
- Green Day - Boulevard of Broken Dreams
- Red Hot Chili Peppers - Can't Stop
- System of a Down - Chop Suey

Para o som de gol, você pode:
- Gravar sua própria narração
- Usar efeitos sonoros gratuitos de sites como Freesound.org
- Usar clips curtos de narrações famosas (uso pessoal apenas)
