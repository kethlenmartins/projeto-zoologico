# Fonte Minecraft (Opcional)

Para o easter egg do Konami Code ter a fonte pixelada do Minecraft, adicione:

- minecraft.ttf (fonte estilo Minecraft)

Fontes similares gratuitas:
- Minecraftia
- Minecrafter
- Mojangles (oficial, mas verificar licença)

Onde conseguir:
1. DaFont.com - procurar por "Minecraft"
2. FontSquirrel.com
3. Google "Minecraft font download"

NOTA: A fonte é OPCIONAL. O modo Minecraft funciona sem ela,
usando Courier New como fallback.
