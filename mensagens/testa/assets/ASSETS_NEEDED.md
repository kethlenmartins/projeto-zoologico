## 🎮 Texturas Minecraft (Opcional para Easter Egg)

### Texturas
- `assets/textures/grass-dirt.png` - Textura de grama/terra do Minecraft (64x64px ou 128x128px)
- `assets/textures/cobblestone.png` - Textura de pedra do Minecraft (64x64px ou 128x128px)

Onde encontrar:
- Extrair do Minecraft (se você tem o jogo)
- Procurar por "Minecraft textures pack" online
- Usar texturas similares criadas por você

### Fonte
- `assets/fonts/minecraft.ttf` - Fonte Minecraft (Mojangles ou similar)

Onde encontrar:
- Procurar por "Minecraft font download"
- Alternativas gratuitas: "Minecraftia", "Minecrafter"

## ℹ️ Notas Importantes

### Sobre Direitos Autorais
- Use apenas fotos que você tem permissão para usar
- Para músicas, considere usar royalty-free ou criar playlist do Spotify
- Texturas do Minecraft são propriedade da Mojang - use apenas para uso pessoal

### Formatos Suportados
- **Imagens**: JPG, PNG, WEBP
- **Áudio**: MP3, OGG, WAV
- **Fontes**: TTF, OTF, WOFF

### Tamanhos Recomendados
- Imagens de perfil: 800x800px (1:1)
- Screenshots de jogos: 800x600px (4:3) ou 1280x720px (16:9)
- Fotos de futebol: 600x600px (1:1) ou qualquer proporção
- Texturas: 64x64px ou múltiplos (128x128, 256x256)
- Áudio: Taxa de bits: 128-192 kbps

### Como Adicionar Assets

1. Copie suas imagens para as pastas correspondentes
2. Renomeie os arquivos para corresponder aos nomes listados acima
3. Se usar nomes diferentes, atualize os caminhos no `index.html`
4. Para testar sem imagens, o site mostra placeholders automáticos

### Teste Sem Assets

O site funciona mesmo sem os assets! Você verá:
- Placeholders para imagens (emoji 📷)
- Mensagens de erro no console para áudio (mas não quebra)
- Modo Minecraft funciona sem texturas (apenas muda cores)
