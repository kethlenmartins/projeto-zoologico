# Projeto Aniversario do Leo

## Como adicionar sua mensagem

Passo 1: Criar sua pasta, seu index.html e sua mensagem

Passo 2: Adicionar link na pagina principal

- Abra o arquivo "index.html" na raiz do projeto e adicione um novo item na lista com seu nome:

```html
<li><a href="mensagens/seunome/index.html">Mensagem do Seu Nome</a></li>
```

### Rodar localmente

Para visualizar o projeto no navegador:

1. npm install
2. node server.js
